## Build checks

Use the Node version in `.nvmrc`, then run `npm ci` and `npm run build`.
Every build first checks Prettier formatting, ESLint with zero warnings,
TypeScript, and Fallow for unused code, dependencies, cycles, duplication, and complexity.
Run `npm run check` for checks alone or `npm run format` to apply formatting.

The root Maven build runs the same frontend checks. See [build checks](../../../HELP.md#build-checks)
for the Java tools and full verification command.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
